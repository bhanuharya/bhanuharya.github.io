  obscuraOS

  Double-click an icon to open it; on a touch screen, tap.
  Right-click (or press and hold) the desktop, icons, title
  bars and taskbar buttons for menus. Drag a window by its
  title bar. Drag it to the top edge to maximize it, or to a
  side to fill half the screen. The button next to Start
  shows the desktop.

  Programs
    Browser          Tabbed browser. Home lists Harya's site and
                     popular sites from around 2000, as the Internet
                     Archive saved them. Type any address (or
                     "site.com 1999") to view it back then, or type
                     words to search posts. Star saves Favorites,
                     Ctrl+F finds text in a page, right-click opens
                     links in new tabs, and Source shows page HTML.
    Packet Capture   every HTTP request this computer makes,
                     live: timing, headers, bytes. Save writes
                     a .har file.
    Terminal         a shell with games (snake, pong, hack). Type help.
    Media Player     music, and YouTube on request. Space plays/pauses;
                     Left/Right arrows seek.
    Notepad          text. It can't save.
    Event Viewer     what happened since you logged on, plus twelve
                     discoveries to find around the desktop.
    Security Center  what this computer sends where.
    Firewall         a game.

  Settings > System Properties shows this device's hardware.
  Settings > Setup changes the display, sounds and boot.
  Click the taskbar clock for a calendar with post links.

  Keys
    /           Find across all posts
    Ctrl+F      Find in the open Browser page
    Alt+T       New Browser tab
    Esc         close menus, find bar, or terminal games
    DEL or F2   Setup, while booting

  Privacy
    Nothing is tracked. Your browser is told to refuse files
    from other sites; YouTube loads only after you press Play
    on a video and agree, and the Internet Archive only after
    you open an old page and agree. Settings and Browser
    Favorites stay in this browser. The log-on name, event log,
    and discoveries go when you close the tab.
