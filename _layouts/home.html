About this site

Static pages generated by Jekyll, hosted on GitHub Pages, styled by one CSS file I wrote by hand. No framework, no build pipeline beyond the generator, no third party scripts.

There is nothing clever tracking you here. The only number on the page is how many times your own browser has loaded it, which stays in your browser.
